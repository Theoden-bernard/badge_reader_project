\section{Stratégie de tests}
Pour \textbf{Badge Reader}, j’ai mis en place une stratégie de tests basée sur :
\begin{itemize}
    \item Les \textbf{tests unitaires} (ExUnit) pour valider la logique métier.
    \item Les \textbf{tests d’intégration} pour vérifier les interactions entre composants.
    \item Les \textbf{tests de performance} pour mesurer la latence sous charge.
\end{itemize}
