\chapter{Tests et qualité logicielle}

\section{Stratégie de tests}
Pour \textbf{Badge Reader}, j’ai mis en place une stratégie de tests basée sur :
\begin{itemize}
    \item Les \textbf{tests unitaires} (ExUnit) pour valider la logique métier.
    \item Les \textbf{tests d’intégration} pour vérifier les interactions entre composants.
    \item Les \textbf{tests e2e} (\textit("End To End")) pour vérifier que tout puisse fonctionner en se mettant à la place d'un utilisateur.
\end{itemize}

\section{Qualité du code}
Je mesure la qualité du code avec :
\begin{itemize}
    \item \textbf{Credo} (analyse statique pour Elixir).
    \item \textbf{ExCoveralls} (couverture de tests).
    \item \textbf{Dialyzer} (détection d’incohérences de types).
    \item \textbf{wallaby} (test e2e).
\end{itemize}
