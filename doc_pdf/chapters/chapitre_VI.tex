\chapter{Sécurité applicative et RGPD}

\section{Protection contre les vulnérabilités OWASP}
Pour sécuriser \textbf{Badge Reader}, j’ai appliqué les recommandations \textbf{OWASP Top 10} en utilisant les outils natifs d’Elixir/Phoenix et des bonnes pratiques spécifiques.
\newline

\begin{for_you}{Mes protections contre les vulnérabilités courantes}
    \textbf{Sécurité intégrée à Phoenix} :
    \begin{itemize}
        \item \textbf{XSS} : Échappement automatique des templates HEEx (équivalent à React).
        \item \textbf{CSRF} : Tokens intégrés dans les formulaires et requêtes.
        \item \textbf{SQL Injection} : Requêtes paramétrées avec Ecto (ORM d’Elixir).
        \item \textbf{Headers de sécurité} : Configuration via \texttt{Plug.Headers}.
    \end{itemize}
\end{for_you}

\begin{for_you}{Exemple d'éléments mis en place}
\textit{Protection XSS} :
    \begin{lstlisting}
    # Dans un template HEEx (lib/badge_reader_web/live/user_live.ex)
    def render(assigns) do
      ~H"""
      <div>
        <!-- Les données sont automatiquement échappées -->
        <h1><%= @user.name %></h1>
        <p><%= @user.bio %></p>

        <!-- Danger : utiliser raw/1 uniquement pour du HTML sûr -->
        <%= raw(@trusted_html) %>
      </div>
      """
    end
    \end{lstlisting}

    \textit{Protection CSRF} :
    \begin{lstlisting}
    # Dans le router.ex
    pipeline :browser do
      plug :accepts, ["html"]
      plug :fetch_session
      plug :fetch_flash
      plug :protect_from_forgery  # Protection CSRF intégrée
      plug :put_secure_browser_headers  # Headers de sécurité
    end
    \end{lstlisting}

    \textit{Requête Ecto (anti-SQL Injection)} :
    \begin{lstlisting}
    # Dans un repository (lib/badge_reader/repos/users.ex)
    def get_user_by_email(email) do
      BadgeReader.Repo.one(
        from u in BadgeReader.Accounts.User,
        where: u.email == ^email,  # ^ force le binding sécurisé
        select: u
      )
    end
    \end{lstlisting}

    \textbf{Headers de sécurité} (dans \texttt{config/config.exs}) :
    \begin{lstlisting}
    config :badge_reader, BadgeReaderWeb.Endpoint,
      url: [host: "localhost"],
      http: [
        port: 4000,
        # Headers de sécurité
        :secure_browser_headers => %{
          "x-frame-options" => "DENY",
          "x-content-type-options" => "nosniff",
          "x-xss-protection" => "1; mode=block",
          "content-security-policy" => "default-src 'self'"
        }
      ]
    \end{lstlisting}
\end{for_you}

\section{Authentification et autorisation}
Pour sécuriser \textbf{Badge Reader}, j’ai mis en place un système d’\textbf{authentification robuste} et une \textbf{gestion fine des autorisations}, en suivant les bonnes pratiques de Phoenix et les exigences de sécurité modernes.

\begin{itemize}
    \item Les \textbf{sessions Phoenix} (stockées côté serveur).
    \item Le \textbf{hachage Bcrypt} pour les mots de passe.
    \item Un \textbf{système de rôles} pour les autorisations.
    \newline
\end{itemize}

\begin{for_you}{Mon système d’authentification}
    \textbf{Authentification par email/mot de passe} :
    Phoenix 1.8.3 fournit une base solide pour l’authentification, que j’ai adaptée pour répondre aux besoins spécifiques du projet.
    \newline

    \textit{Exemple de contrôleur d’authentification} :
    \begin{lstlisting}
  # lib/badge_reader_web/controllers/user_auth_controller.ex
  defmodule BadgeReaderWeb.UserAuthController do
    use BadgeReaderWeb, :controller
    use Phoenix.Controller, :auth

    # Connexion utilisateur
    defp create(conn, %{"user" => user_params}, info) do
      %{"email" => email, "password" => password} = user_params

      if user = Accounts.get_user_by_email_and_password(email, password) do
        conn
        |> put_flash(:info, info)
        |> UserAuth.log_in_user(user, user_params)
      else
        # In order to prevent user enumeration attacks, don't disclose whether the email is registered.
        conn
        |> put_flash(:error, "Invalid email or password")
        |> put_flash(:email, String.slice(email, 0, 160))
        |> redirect(to: ~p"/users/log-in")
      end
    end

    # Déconnexion
    def delete(conn, _params) do
      conn
      |> put_flash(:info, "Logged out successfully.")
      |> UserAuth.log_out_user()
    end
  end
    \end{lstlisting}

    \textit{Points clés} :
    \begin{itemize}
        \item Utilisation des \textbf{sessions Phoenix} (sécurisées par défaut).
        \item Gestion des \textbf{flash messages} pour les retours utilisateur.
        \item Redirections après succès/échec.
    \end{itemize}
\end{for_you}

\begin{for_you}{Gestion des mots de passe avec Bcrypt}
    \textbf{Hachage sécurisé des mots de passe} :
    Phoenix 1.8.3 utilise \textbf{Bcrypt} par défaut pour le hachage.
    \newline

    \textit{Exemple de schéma utilisateur} :
    \begin{lstlisting}
    # lib/badge_reader/accounts/user.ex
    defmodule BadgeReader.Accounts.User do
      use Ecto.Schema
      import Ecto.Changeset

      schema "users" do
        field :email, :string
        field :password, :string, virtual: true, redact: true
        field :hashed_password, :string, redact: true
        field :confirmed_at, :utc_datetime
        field :authenticated_at, :utc_datetime, virtual: true

        timestamps(type: :utc_datetime)
      end

      # Changeset pour l'inscription
      def registration_changeset(user, attrs) do
        user
        |> cast(attrs, [:email, :password])
        |> validate_required([:email, :password])
        |> validate_format(:email, ~r/^[^\s]+@[^\s]+$/)
        |> validate_length(:password, min: 12)
        |> put_password_hash()  # Hachage Bcrypt
      end

      # Fonction de hachage (générée par phx.gen.auth)
      defp put_password_hash(changeset) do
        case changeset do
          %Ecto.Changeset{valid?: true, changes: %{password: pass}} ->
            put_change(changeset, :hashed_password, Bcrypt.hash_pwd_salt(pass))
          _ ->
            changeset
        end
      end
    end
    \end{lstlisting}

    \textit{Pourquoi Bcrypt ?} :
    \begin{itemize}
        \item \textbf{Sécurité prouvée} : Résistant aux attaques par force brute.
        \item \textbf{Paramètres par défaut} : Cost factor à 12 (recommandé).
        \item \textbf{Intégré à Phoenix} : Pas besoin de dépendance externe.
    \end{itemize}
\end{for_you}

\begin{for_you}{Gestion des sessions et sécurité}
    \textbf{Sécurité des sessions} :
    Phoenix utilise un système de \textbf{sessions signées et chiffrées} pour garantir la sécurité.
    \newline

    \textit{Configuration des sessions} :
    \begin{lstlisting}
    # config/config.exs
    config :badge_reader, BadgeReaderWeb.Endpoint,
      session_store: :cookie,
      secret_key_base: System.get_env("SECRET_KEY_BASE"),
      signing_salt: "session",
      encryption_salt: "session_encrypt",
      key: "_badge_reader_key",
      store: :cookie,
      max_age: 604_800  # 7 jours
    \end{lstlisting}

    \textit{Exemple de plug pour fetch l’utilisateur courant} :
    \begin{lstlisting}
    # lib/badge_reader_web/plugs/fetch_current_user.ex
    defmodule BadgeReaderWeb.Plugs.FetchCurrentUser do
      import Plug.Conn

      def init(opts), do: opts

      def call(conn, _opts) do
        user_id = get_session(conn, :user_id)

        if user_id do
          user = Accounts.get_user!(user_id)
          assign(conn, :current_user, user)
        else
          conn
        end
      end
    end
    \end{lstlisting}

    \textit{Pourquoi ce système de sessions ?} :
    \begin{itemize}
        \item \textbf{Sécurité} : Les cookies sont signés et chiffrés.
        \item \textbf{Simplicité} : Pas besoin de gérer des tokens côté client.
        \item \textbf{Intégré à Phoenix} : Fonctionne directement avec les contrôleurs et plugs.
    \end{itemize}
\end{for_you}

\section{Conformité RGPD}

Pour respecter le \textbf{RGPD}, j’ai implémenté :
\begin{itemize}
    \item Un \textbf{registre des traitements}.
    \item La \textbf{minimisation des données}.
    \item Les \textbf{droits des utilisateurs} (accès, rectification, effacement).
    \item Le \textbf{chiffrement} des données sensibles.
    \newline
\end{itemize}

\begin{for_you}{1. Gestion des données utilisateurs :}
    \begin{lstlisting}
    # lib/badge_reader/accounts/user.ex
     
    def password_changeset(user, attrs, opts \\ []) do
      user
      |> cast(attrs, [:password])
      |> validate_confirmation(:password, message: "does not match password")
      |> validate_password(opts)
      end

    defp validate_password(changeset, opts) do
      changeset
      |> validate_required([:password])
      |> validate_length(:password, min: 12, max: 72)
      |> maybe_hash_password(opts)
    end

    defp maybe_hash_password(changeset, opts) do
      hash_password? = Keyword.get(opts, :hash_password, true)
      password = get_change(changeset, :password)

      if hash_password? && password && changeset.valid? do
        changeset
        |> validate_length(:password, max: 72, count: :bytes)
        |> put_change(:hashed_password, Bcrypt.hash_pwd_salt(password))
        |> delete_change(:password)
      else
        changeset
      end
    end
    \end{lstlisting}

    \textit{Points clés} :
    \begin{itemize}
        \item \textbf{Hachage des mots de passe} : Utilisation de \textbf{Bcrypt} (intégré à Phoenix).
        \item \textbf{Validation des emails} : Format strict et unicité en base.
        \item \textbf{Champs RGPD} : \texttt{confirmed\_at} pour le consentement explicite.
    \end{itemize}
\end{for_you}

\begin{for_you}{2. Gestion des droits utilisateurs (RGPD) :}
    \begin{lstlisting}
    # lib/badge_reader/accounts.ex
    defmodule BadgeReader.Accounts do
      import Ecto.Query

      # Droit d'accès (Article 15 RGPD)
      def get_user_data(user_id) do
        Repo.one(
          from u in User,
          where: u.id == ^user_id,
          select: %{email: u.email, role: u.role, created_at: u.inserted_at}
        )
      end

      # Droit à l'effacement (Article 17 RGPD)
      def delete_user(user_id) do
        Repo.transaction(fn ->
          # Suppression des badges associés
          Repo.delete_all(from b in Badge, where: b.user_id == ^user_id)
          # Anonymisation de l'utilisateur (plutôt que suppression)
          Repo.update!(User, set: [email: "deleted-#{user_id}@example.com"], id: user_id)
        end)
      end

      # Droit à la portabilité (Article 20 RGPD)
      def export_user_data(user_id) do
        user = Repo.get!(User, user_id)
        badges = Repo.all(from b in Badge, where: b.user_id == ^user_id)
        %{user: user, badges: badges}
      end
    end
    \end{lstlisting}

    \textit{Conformité RGPD} :
    \begin{itemize}
        \item \textbf{Droit d’accès} : \texttt{get\_user\_data/1} retourne uniquement les données personnelles.
        \item \textbf{Droit à l’oubli} : \texttt{delete\_user/1} anonymise (ne supprime pas pour garder la traçabilité).
        \item \textbf{Portabilité} : \texttt{export\_user\_data/1} retourne un JSON structuré.
    \end{itemize}
\end{for_you}

\begin{for_you}{3. Chiffrement des données sensibles (sécurité RGPD)}
    Phoenix 1.8.3 utilise \textbf{Bcrypt} pour les mots de passe et permet d’ajouter du chiffrement supplémentaire pour les données critiques.

    \begin{lstlisting}
    # lib/badge_reader/security.ex
    defmodule BadgeReader.Security do
      @aes_key Application.compile_env(:badge_reader, :aes_key) || raise "AES_KEY missing"

      def encrypt(data) when is_binary(data) do
        iv = :crypto.strong_rand_bytes(16)  # Vecteur d'initialisation
        encrypted = :crypto.block_encrypt(:aes_256_cbc, @aes_key, iv, data)
        Base.encode64(iv <> encrypted)  # Format stockage
      end

      def decrypt(encoded_data) do
        decoded = Base.decode64!(encoded_data)
        <<iv::binary-16, encrypted::binary>> = decoded
        :crypto.block_decrypt(:aes_256_cbc, @aes_key, iv, encrypted)
      end
    end
    \end{lstlisting}

    \textit{Exemple d’utilisation} :
    \begin{lstlisting}
    # Dans un schéma Ecto pour chiffrer un champ sensible
    defmodule BadgeReader.Badge do
      use Ecto.Schema

      schema "badges" do
        field :user_id, :integer
        field :badge_number, :string, encrypted: true  # Champ chiffré
        field :expiry_date, :date
      end

      def changeset(badge, attrs) do
        badge
        |> cast(attrs, [:badge_number, :expiry_date])
        |> validate_required([:badge_number])
        |> encrypt_sensitive_fields()
      end

      defp encrypt_sensitive_fields(changeset) do
        case changeset do
          %Ecto.Changeset{changes: %{badge_number: number}} ->
            encrypted = Security.encrypt(number)
            put_change(changeset, :badge_number, encrypted)
          _ ->
            changeset
        end
      end
    end
    \end{lstlisting}
  \end{for_you}
