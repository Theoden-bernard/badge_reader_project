\chapter{Déploiement et CI/CD}

\section{Containerisation avec Docker}

Pour standardiser les environnements de développement et de production, j’ai choisi, dans le cadre de mon PFE, \textbf{Docker}.
Cette solution permet :
\begin{itemize}
    \item Une \textbf{reproductibilité} totale des déploiements.
    \item Une \textbf{isolation} des dépendances (Elixir, PostgreSQL, etc.).
    \newline
\end{itemize}

\begin{for_you}{Dockerfile :}
\begin{lstlisting}[language=dockerfile]
# Image of elixir
FROM elixir:1.18

RUN apt-get update \
    && apt-get install -y nodejs npm \
    && rm -rf /var/lib/apt/list/* \
    && apt-get update && apt-get install -y inotify-tools

# Working directory 
WORKDIR /app

# Copy my file -> conteneur
COPY . .

ENV MIX_ENV="prod"

# Bash command
RUN set -xe \
&& mix local.hex --force \
&& mix archive.install hex phx_new --force \
&& mix deps.get \
&& mix deps.compile

RUN mix compile

RUN cd assets && npm install

RUN mix assets.deploy \
    && mix phx.digest

CMD ["mix", "phx.server"]

\end{lstlisting}
\end{for_you}

\newpage

Nous utiliserons ensuite un Docker-compose qui orchestra les services (application, base de données) pour un environnement complet.
\newline

\begin{for_you}{Docker Compose pour l'environnement complet :}
\begin{lstlisting}[language=yaml]
services:
  web:
    depends_on:
      - db
    tty: true
    image: theoden714/badge_reader:latest
    
    ports:
      - "4000:4000"
    volumes:
      - ./badge_reader:/app
    environment:
      MIX_ENV: "prod"
      DATABASE_URL: "postgresql://${POSTGRES_USER}:${POSTGRES_PASSWORD}@db:5432/${POSTGRES_DB}"
      SECRET_KEY_BASE: ${SECRET_KEY_BASE}
      PHX_HOST: ${PHX_HOST}
  db:
    image: postgres:14
    ports:
      - "5432:5432"
    restart: always
    shm_size: 128mb
    
    environment:
      POSTGRES_USER: ${POSTGRES_USER}
      POSTGRES_PASSWORD: ${POSTGRES_PASSWORD}
      POSTGRES_DB: ${POSTGRES_DB}
      
    volumes:
      - postgres_data:/var/lib/postgresql/data
volumes:
  postgres_data:

\end{lstlisting}

Dans mon Docker-compose, j'ai utilisé des "Secrets-keys". Ce sont des outils mis à disposition pour éviter de partager des données sensibles.
Ces données sont directement stockées et gérées par GitHub.
\end{for_you}

\section{Pipeline CI/CD avec GitHub Actions}

Le pipeline CI/CD automatise les étapes de linting, build, test, scan de sécurité et déploiement. GitHub Actions exécute ces étapes à chaque push et Pull Request, garantissant la qualité du code avant intégration. Les secrets et variables d'environnement sécurisent les informations sensibles.

\begin{for_you}{Workflow GitHub Actions partie CI 1/2}
\begin{lstlisting}[language=yaml]
name: CI

on:
    push:
        branches: ["develop"]
    
    pull_request:
        branches: ["main", "develop"] 

env:
    MIX_ENV: test

jobs:
    test:
      runs-on: ubuntu-latest

      defaults:
        run:
          working-directory: ./badge_reader

      env:
        POSTGRES_USERNAME: "postgres"
        POSTGRES_PASSWORD: "postgres"
        POSTGRES_DATABASE: "badge_reader_test"

      services:
        postgres:
          image: postgres:15
          env:
            POSTGRES_USER: "postgres"
            POSTGRES_PASSWORD: "postgres"
            POSTGRES_DB: "badge_reader_test"
          options: >-
            --health-cmd pg_isready
            --health-interval 10s
            --health-timeout 5s
            --health-retries 5
          ports:
            - 5432:5432
      
      steps:
          - uses: actions/checkout@v7 

          - name: Set up Elixir & Erlang
            uses: erlef/setup-beam@v1
            with:
              elixir-version: "1.18"
              otp-version: "27"
\end{lstlisting}
\end{for_you}

\begin{for_you}{Workflow GitHub Actions partie CI 2/2}

\begin{lstlisting}[language=yaml]
          - name: Restore dependencies cache
          uses: actions/cache@v4
          with:
            path: badge_reader/deps
            key: ${{ runner.os }}-mix-${{ hashFiles('badge_reader/**/mix.lock') }}
            restore-keys: ${{ runner.os }}-mix-

          - name: Install dependencies
            run: mix deps.get

          - name: Setup Database
            run: |
              mix ecto.create
              mix ecto.migrate
              mix run priv/repo/seeds.exs

          - name: Compile
            run: mix compile --warnings-as-errors

          - name: Run tests
            run: mix quality  

    build_and_push_image:
        runs-on: ubuntu-latest
        needs: test

        steps:
            - name: Clonage du repo
              uses: actions/checkout@v7
          
            - name: Installation docker
              uses: docker/setup-qemu-action@v3

            - name: Set up Docker Buildx
              uses: docker/setup-buildx-action@v3

            - name: Login to Docker Hub
              uses: docker/login-action@v3
              with:
                username: ${{ secrets.LOGIN }}
                password: ${{ secrets.PASSWORD }}

            - name: Build & Push
              uses: docker/build-push-action@v6
              with:
                context: ./badge_reader
                push: true
                tags: ${{ secrets.LOGIN }}/badge_reader:latest
\end{lstlisting}
\end{for_you}

\begin{for_you}{Workflow GitHub Actions partie CD :}
\begin{lstlisting}[language=yaml]
name: cd_badge_reader

on:
    push:
        branches: ["main"]

jobs:
    production:
        runs-on: ubuntu-latest

        steps:

            - name: Ecriture shh key
              run: |
                echo "${{ secrets.SSH_KEY_AWS }}" > key.pem
                chmod 400 key.pem

            - name: ajoute Ec2 aux known_hosts
              run: |
                mkdir -p ~/.ssh
                touch ~/.ssh/known_hosts
                chmod 644 ~/.ssh/known_hosts
                ssh-keyscan ${{ secrets.EC2_IP }} >> ~/.ssh/known_hosts
                
            - name: Conection Ec2
              run: |
                ssh -i key.pem ${{ secrets.EC2_USER }}@${{ secrets.EC2_IP }} << 'EOF'
                echo "Connexion OK"
                docker-compose down
                docker system prune -a --volumes -f
                docker pull theoden714/badge_reader:latest
                docker-compose up -d
                EOF

            - name: Supression de la clef
              run: rm -f key.pem
\end{lstlisting}
\end{for_you}
